Guide the user through one tiny, reversible OpenSpec change.

1. Load the `openspec` skill and inspect the codebase for two or three safe opportunities.
2. Let the user select one, then narrate the workflow: `/opsx-new`, planning artifacts, `/opsx-apply`, `/opsx-verify`, and `/opsx-archive`.
3. Pause for explicit confirmation before every file-changing phase.

Keep this a tutorial rather than a feature sprint.
